# Star-Tracking Ritual

A weekly check-in on the open-source funnel: GitHub stars → site visits → signups.
Fill this in once a week (same day/time if possible). Stars are the repo's star count;
GH→site visits are clicks on the UTM-tagged README links
(`utm_source=github-widget&utm_medium=readme`); signups are Bellnote accounts
attributed to that campaign.

## Working assumption

> Every sustained **+100 stars** should produce a measurable site-visit bump within a
> week. If it doesn't, the README funnel is broken — audit the CTA links, the UTM
> parameters, and the landing page before doing anything else.

## Targets

| Milestone | Stars |
|---|---|
| Day 30 | 100 |
| Day 60 | 250 |
| Day 90 | 500 |
